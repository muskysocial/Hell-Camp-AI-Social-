Install guide
Free to install

Your community, one tap away.

Add Hell Camp to your phone's Home Screen for an app-like experience. Installation is free; paid coins and services inside Hell Camp remain subject to their existing prices.

Open Hell Camp

Android

  1. Open Hell Camp in Google Chrome.
  2. Tap Chrome's ⋮ menu in the top corner.
  3. Choose Install app. If that option is not available, choose Add to Home screen.
  4. Confirm, then open Hell Camp from the new Home Screen icon.

iPhone or iPad

  1. Open Hell Camp in Safari (not inside another app's mini-browser).
  2. Tap the Share button.
  3. Scroll and select Add to Home Screen.
  4. Tap Add, then launch Hell Camp from the Home Screen.

If the option is missing, check that you opened the site in Safari and that your iOS version supports Home Screen web apps.

Before you start

Keep an internet connection for sign-in, feeds, payments, coins, HELL EDITS, and Hell Boost. Adding the shortcut does not create a new account or change your existing account.
